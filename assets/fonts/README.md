# Fonts for generated images

Used only by `src/app/[locale]/resources/[slug]/opengraph-image.tsx` to render Open Graph images. The site itself loads fonts through `next/font`.

- Geist Medium (500), Geist SemiBold (600) and Geist Mono Medium (500), from Google Fonts.
